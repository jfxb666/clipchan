## 剪贴板酱 Clipchan 0.6.0

Windows 剪贴板历史工具。Ctrl+` 唤起面板，选中即粘贴回刚才那个窗口。
这一版把九个长期缺口一次补齐：**文件记录**、**按应用排除**、**自动更新**、**拼音搜索**、**拖出到外部**、**片段库**、**富文本保真**、**批量操作**、**粘贴为纯文本**。

### 下载

- **免安装版** `Clipchan.exe` — 双击即用，不要求安装任何运行时。
- **安装版** `Clipchan-Setup-0.6.0.exe` — 装到 `%LOCALAPPDATA%\Programs\Clipchan`，可从「设置 → 应用」卸载。

装过 0.5.0 的，这一版起可以在「设置 → 版本与更新」里点「检查更新」，之后会自动提示并下载新版本。

### 新增：文件记录

在资源管理器里复制文件，现在会被记下来，卡片显示「文件 报告.pdf 等 3 个」这样的摘要。

- **粘贴/复制会把文件真正放回剪贴板**，贴进资源管理器就是那批文件本身，不是一串路径字符串。
- 拖到资源管理器也能直接把文件拖出去（见下）。
- 搜索能按文件名找到它。
- 只记路径，**不复制文件内容**，不占额外磁盘。原文件被移走后粘贴会提示「文件已不在原位置」。

### 新增：按应用排除（隐私）

「设置 → 排除的应用」可以列出**永远不要记录**的程序，例如 `1Password.exe`、`KeePass.exe`。

- 从这些程序复制的东西**整条丢弃**，不落库、不出现在列表里、也搜不到。
- 填完整路径或只填 exe 名都行，程序统一取文件名比较（不区分大小写）。
- 附了几个常用密码管理器的快捷选项。

### 新增：片段库

左侧栏多了「片段」。常用的地址、签名、命令、模板存成片段，用的时候点一下就写进剪贴板并直接粘贴。

- 每条有标题和内容，标题留空就用内容首行当名字。
- 记「用过几次」，常用的自动排在前面。
- 上限 200 条，可改可删（删除要就地二次确认）。

### 新增：拼音搜索

搜索框现在认拼音。输入 `shougong` 或首字母 `sgys` 都能找到「手工验收已完成」。

- 中文、全拼、首字母三路同时匹配，不用切换输入法再打一遍。
- 中英混排、数字、路径照样能搜。

### 新增：拖出到外部

卡片可以直接拖到别的程序里 —— 拖到资源管理器是导出文件，拖到聊天窗口是发图片。

### 新增：富文本保真

复制网页上带格式的内容（加粗、列表、表格），粘贴到 Word / 邮件 / 飞书里**格式还在**。粘贴到记事本这类只认纯文本的地方，自动退回纯文本，不会变成一堆 HTML 源码。

### 新增：批量操作

选中多条之后，底部会出现操作栏：**批量粘贴**（按选中顺序用换行拼成一段）、**批量收藏 / 取消收藏**、**批量删除**。

### 新增：粘贴为纯文本

`Ctrl+Shift+V` 粘贴时丢掉所有格式，只贴文字。从网页复制的一段带样式的文字，贴进代码编辑器里不会再带一堆颜色和链接。

### 改进

- **搜索不再是全表扫**：加了索引列，几千条历史里搜关键词明显更快。
- 右键菜单在图片记录上多了「识别文字」，非图片记录上多了「粘贴为纯文本」。

### 修复

- **复制文件记录后粘不出文件**。之前是用 Electron 的剪贴板接口写文件列表，实测它写出来的是一个**自定义格式**（枚举出来 id 49159、名字 `FileNameW`），根本不是标准的 `CF_HDROP`(15)，资源管理器和别的程序一律读不到。现在读和写都交给原生助手走真正的 `CF_HDROP`。
- 同理，**从资源管理器复制文件时读不到路径**也是这个原因 —— Electron 读别人写的 `CF_HDROP` 会返回空。

### 数据兼容

- 老库（v0.5.0 及更早）直接打开，首次启动自动升级到 schema v3，已有的记录、回收站、设置项全部原样保留。
- 升级会给已有记录补建拼音索引，几万条也只要一两秒。

### 环境

Windows 10 / 11 x64。数据全部落在 `%APPDATA%\Clipchan\`。

### 已知边界

- **文件记录只记路径**，不复制内容。原文件被移动或删除后，粘贴会如实提示，不会假装成功。
- **富文本只保留 `text/html` 原样**，不做清洗与重排；粘贴到不支持 HTML 的地方自动退回纯文本。
- **片段库只存纯文本**，不支持图片与附件。
- **拼音搜索靠预建索引列**，不是 SQLite 的 FTS5（实测 FTS5 的 trigram 分词器对两字中文词不命中）。所以搜索的是「已经写进索引的那一刻」的内容，改不了历史记录的索引。
- **自动更新只走 GitHub Releases**，国内网络可能连不上，此时「检查更新」会如实报错，不影响正常使用。
- **排除的应用只认 exe 名**，同一个程序换个名字就绕过去了；这是防手滑，不是防恶意软件。
- Win10 上「毛玻璃」是窗口内模糊，不是系统级 acrylic。
- 提权窗口因 UIPI 无法自动粘贴，会回退为「已复制，按 Ctrl+V 粘贴」。
- API Key 以明文存放在本地 `clipchan.db`，不加密。
- 手机端只搭了壳，本版新增能力都只在桌面端。
