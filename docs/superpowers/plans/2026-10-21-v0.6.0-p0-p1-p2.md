## 1. 三条铁律（沿用 v0.5.0）

1. **绝对路径不出主进程**：文件记录只存相对路径/计数，DTO 只给 `fileCount`。
2. **契约链五处同步**：`types.ts` → `channels.ts` → `main.ts` handler → `preload.ts`（单行）→ `preload.spec.ts` EXPECTED。漏一处 = 运行时 `not-implemented`。
3. **删盘只有一个入口**：`purgeItemsWithFiles`。文件记录删记录时也必须走它。

- **第一波（并行）**：A / B / C / D。各自只跑自己 spec 的 vitest，**不跑全项目 typecheck**（其他人的文件同时在改，必然红）。
