# v1.2 功能批（A/C/D/E 九项）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地用户选定的 9 项功能：数字键速贴、条目编辑再粘贴、拼接格式可选、一键整理向导、查看器命中高亮、片段变量、自定义 AI 动作、OCR 联动、通用格式导出。

**Architecture:** 全部落在既有分层内：纯逻辑进 `@clipchan/core`（keymap/expand/export builder/高亮），主进程能力经 `channels.ts` → `preload.ts` → `types.ts`（PlatformAdapter）→ `store.ts` 接线；持久化复用 settings 表（类型化字段走 sanitizeSettings 白名单，非类型化走 getSettingValue KV——与 aiProviders 同款）。历史记录保持不可变：编辑再粘贴不改原条目。

**Tech Stack:** 不变。零新增依赖。vitest node 环境（无 jsdom），UI 逻辑一律抽纯函数测试。

**全局约束（每任务隐含）：**
- 门禁三连：`pnpm typecheck && pnpm test && node scripts/smoke-main.mjs`，全绿才提交；提交只含本任务文件。
- 中文文案；注释只写"为什么"、★ 开头标重点。
- 新 IPC 通道会被 smoke 的源码计数断言自动覆盖（现 77 → 增加），不许改断言放水。
- vitest node 环境：UI 组件不直接测，交互逻辑抽成纯函数放 logic/ 或与组件同目录的 spec。
