## 剪贴板酱 Clipchan 0.4.0

Windows 剪贴板历史工具。Ctrl+` 唤起面板，选中即粘贴回刚才那个窗口。
这一版只改"怎么看"：同一批记录多了三种排法，代码复制过来能直接看懂。

### 下载

- **免安装版** `Clipchan.exe` — 双击即用，不要求安装任何运行时（首次启动会解压到临时目录，约 3–5 秒）。
- **安装版** `Clipchan-Setup-0.4.0.exe` — 装到 `%LOCALAPPDATA%\Programs\Clipchan`，可从「设置 → 应用」卸载。

### 新增：三种排列方式

顶部搜索框右侧多了四个图标按钮：**列表 / 时间轴 / 瀑布流 / 按来源**。它们只换"同一批记录怎么排"，不改变你筛选的内容——「只看图片 + 瀑布流」这种组合照常可用。

- **时间轴**：按天分组，日期标题吸顶。今天 / 昨天 / 8月14日 / 2024年8月14日，越久远写得越完整。
- **瀑布流**：按窗口宽度自动排 1–4 列，图片按真实宽高比显示，不再被裁成一条。文本卡按行数估高，长文本不会被挤成两行。
- **按来源**：按复制来源的程序分组，组标题右侧标出条数，组按"组内最新一条"倒序排。来源名去掉了 `.exe` 后缀（`Code.exe` 显示成 `Code`）；取不到来源的记录归到「未知来源」，固定排在最后——它不是一个来源，排在最前会让人误以为是最活跃的应用。

选过的排列方式会记住，下次打开还是那个。

### 新增：代码语法高亮

- 文本记录如果被判定成代码，列表卡片和「查看全文」里都会按语法着色（关键字、字符串、注释、数字分开配色）。
- 支持 13 种语言：JavaScript / TypeScript / Python / Java / C# / C++ / Go / Rust / JSON / XML(含 HTML、SVG) / CSS / Shell / SQL。
- 只对**已被判定为代码**的记录生效；普通文字、长文章不会莫名其妙变色。
- 超过 8000 字的文本不做高亮，避免长内容拖慢列表滚动。
- 配色跟着主题走，深浅色主题都能看清。

### 改进

- 侧边栏「全部 / 文本 / 图片」下面多了常驻的**「优化」**入口，不必先选中一条记录才能打开提示词优化（打开后可以手输原文）。
- 切换排列方式时列表自动回到顶部——换了排法还停在原来的滚动位置，会落在一条毫不相干的记录上。
- 图片记录现在会记住原始宽高，瀑布流据此按真实比例排版。

### 数据兼容

- 老库（v0.3.0）直接打开，不需要迁移步骤。新增的"排列方式"设置项在旧库里不存在时默认取「列表」，升级后界面行为不突变。
- 图片的宽高是可选字段：老记录没有就按固定高度排，不会显示成 0。

### 环境

Windows 10 / 11 x64。数据全部落在 `%APPDATA%\Clipchan\`。

### 已知边界

- **搜索时只有搜索词高亮，没有语法高亮。** 两套着色叠在一起会让代码片段错乱，所以搜索态下让位给搜索词高亮。
- 语言是**按文本特征猜的**，不是让用户选。猜不出来就不高亮（显示成普通文本），不会乱涂色。混合语言的片段可能只认主语言。
- 瀑布流里文本卡的高度是**估算**的（按行数），只用于决定放进哪一列；估偏了最多是列高不齐，不会错位。
- 三种排列方式共用同一套分页：滚到底加载下一页，不是在本地重排全部历史。
- 回收站不参与搜索、分类、词云，也不支持这三种排列方式，它只是一个按删除时间倒序的分页列表。
- Win10 上「毛玻璃」是窗口内模糊，不是系统级 acrylic。
- 提权窗口因 UIPI 无法自动粘贴，会回退为「已复制，按 Ctrl+V 粘贴」。
- 只记录文本与图片。
- API Key 以明文存放在本地 `clipchan.db`，不加密。
- 手机端只搭了壳，三种排列方式与语法高亮在手机端不提供。
