## 剪贴板酱 Clipchan 0.3.0

Windows 剪贴板历史工具。Ctrl+` 唤起面板，选中即粘贴回刚才那个窗口。
这一版只做一件事：**让"删错了"不再等于"永久丢"**，顺带补上来源应用与可迁移的备份。

### 下载

- **免安装版** `Clipchan.exe` — 双击即用，不要求安装任何运行时（首次启动会解压到临时目录，约 3–5 秒）。
- **安装版** `Clipchan-Setup-0.3.0.exe` — 装到 `%LOCALAPPDATA%\Programs\Clipchan`，可从「设置 → 应用」卸载。

### 新增：回收站与撤销

- 删除不再是硬删：`Delete`、右键删除、清空未收藏、超出「历史上限」被淘汰的记录，全都先进**回收站**，原图与缩略图原样留在盘上。
- 删除后提示条上直接有「撤销」，3 秒内也可以按 **`Ctrl+Z`**（搜索框聚焦时不抢这个键）。
- 回收站是左侧栏底部的独立视图，按删除时间倒序分页。逐条「恢复」回到**原来的时间位置**，不是回到最顶上。
- 删掉之后又复制了同样内容时，恢复会明确提示「同内容已在列表中，无需恢复」，不会覆盖你新复制的那条。
- 回收站有自己的上限（设置 → 数据 →「回收站上限」，默认 200），超出按最旧淘汰。
- **永久删除与清空回收站会真删盘，不可撤销**，所以都要点两次（3 秒窗口）。

### 新增：zip 导入导出

- 「导出为 zip」弹系统保存对话框，包内是 `manifest.json` + `images/` 原图 + `thumbs/` 缩略图；只导活跃记录，不含回收站内容。
- 「导入备份包」是**加法不覆盖**：重复 id、重复内容哈希、重复图片哈希一律跳过，现有数据一条都不改。坏条目跳过并计数，好的照进；整批在一个事务里，失败回滚并清理已落盘文件。
- 原图丢失的条目照样能导出（该条没有图，提示里报「缺图 N 条」）。
- 上一版那个写到数据目录、不给选位置的「导出 JSON」已被 zip 导出取代。

### 新增：来源应用

- 每条记录会记下它是从哪个程序复制的，只记 **exe 名**（如 `Code.exe`、`msedge.exe`），不记窗口标题、不记路径。
- 取不到就留空，界面不显示，不写「未知」这类假值；从面板粘贴回写的内容不会把 Clipchan 自己记成来源。

### 数据兼容

- 老库（v0.2.0）首次打开会自动迁移：补 `deleted_at` / `source_app` 两列、重建两个唯一索引，**记录一条不丢**。
- 迁移用 `PRAGMA user_version` 记账，重复启动不会重复执行。

### 环境

Windows 10 / 11 x64。数据全部落在 `%APPDATA%\Clipchan\`。

### 已知边界

- 回收站不参与搜索、分类、词云，它只是一个分页列表。
- 清空回收站不可撤销（硬删）。
- 导入不触发「历史上限」淘汰：悄悄把刚导进来的记录踢进回收站比超限更糟，超出部分靠后续正常复制自然收敛。
- Win10 上「毛玻璃」是窗口内模糊，不是系统级 acrylic。
- 提权窗口因 UIPI 无法自动粘贴，会回退为「已复制，按 Ctrl+V 粘贴」。
- 只记录文本与图片。
- API Key 以明文存放在本地 `clipchan.db`，不加密。
- 手机端只搭了壳，回收站与导入导出在手机端明确提示「暂不支持」。
