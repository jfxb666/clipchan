## 剪贴板酱 Clipchan 0.5.0

Windows 剪贴板历史工具。Ctrl+` 唤起面板，选中即粘贴回刚才那个窗口。
这一版加了三件事：**截图标注**、**图片文字识别**、**提示词优化历史**。

### 下载

- **免安装版** `Clipchan.exe` — 双击即用，不要求安装任何运行时。
- **安装版** `Clipchan-Setup-0.5.0.exe` — 装到 `%LOCALAPPDATA%\Programs\Clipchan`，可从「设置 → 应用」卸载。

### 新增：截图标注（Ctrl+Alt+S）

按 **Ctrl+Alt+S**，屏幕被压暗，拖一个框就开始标注。选中的那块会自动存成一条图片记录，同时默认复制到剪贴板。

- **工具**：矩形、箭头、画笔、文字、马赛克，五种。
- **撤销**：标错了按 Ctrl+Z 或点工具栏的「撤销」退回上一步。
- **颜色**：工具栏里可换笔色。
- **完成后三种去处**：复制到剪贴板（默认）/ 粘贴回刚才那个窗口 / 存成文件。
- **取消**：按 Esc，或右键。

### 新增：图片文字识别（OCR）

图片记录右键多了「识别文字」。

- 识别结果显示在独立面板里，可**一键复制**，也可**存为一条新记录**（存成普通文本记录，之后能被搜索到）。
- 中英文混合识别。引擎是 tesseract.js（WASM），不联网也能用。
- **首次使用要先下载语言包**（约 4.7MB，在「设置 → 文字识别」里点下载）。下载源固定、带 SHA-256 校验，断网或校验失败会给中文原因，不会假装成功。

### 新增：提示词优化历史

优化面板右上角多了「历史」。

- 每次优化成功后自动留档：**原文 + 结果全文 + 场景 + 模式 + 模型 + 时间**。
- 最多保留 **100 条**，超出自动淘汰最旧的。
- 可以单条删除，也可以一键清空（清空前会二次确认）。
- 点历史里的任意一条，原文与结果直接填回面板，不用重新跑一遍。

### 改进

- 截图遮罩窗现在覆盖到任务栏那一块。之前的版本底部会少 40px，框不到屏幕最下面。

### 数据兼容

- 老库（v0.4.0）直接打开，不需要手动迁移。新增的 `optimize_history` 表在首次启动时自动建好。
- 已有的剪贴板记录、回收站、设置项全部原样保留。

### 环境

Windows 10 / 11 x64。数据全部落在 `%APPDATA%\Clipchan\`（截图与语言包也在这里）。

### 已知边界

- **截图不做长截图、不做图层、不加水印与气泡**，只做上面那五种标注。
- **OCR 的语言是固定的中英文**，不做语言选择，也不做翻译。
- **OCR 对屏幕上的小字准确率有限**。屏幕截图里的正文通常是 12–14px，识别引擎对这么小的中文错字率不低；把图放大后再识别会好一些，程序已经做了自动放大，但源图太小仍然会错。文档扫描件、代码截图这类大字号内容效果明显更好。
- **OCR 结果不会自动修正错字**，识别出来什么就显示什么，需要人工核对。
- 截图热键是**第三个**热键槽位，与唤起面板（Ctrl+`）、小组件各占一个。三个热键都可以在设置里改。
- 提示词优化历史只存在本机 `clipchan.db`，不同步、不导出。
- Win10 上「毛玻璃」是窗口内模糊，不是系统级 acrylic。
- 提权窗口因 UIPI 无法自动粘贴，会回退为「已复制，按 Ctrl+V 粘贴」。
- 只记录文本与图片。
- API Key 以明文存放在本地 `clipchan.db`，不加密。
- 手机端只搭了壳，截图、OCR、优化历史在手机端都不提供。
