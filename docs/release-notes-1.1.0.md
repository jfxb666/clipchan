## 剪贴板酱 Clipchan 1.1.0

这一版没有新增大功能，做的是一次**全面体检**：工程质量审计提出的 23 项技术债，能不动产品行为的 19 项在这版全部落地 —— 数据库更快、搜索更快、批量操作不闪、升级失败不再白屏，外加一串界面修复。每一项都有测试钉住，全套 1740 条测试通过。

不添服务器、不添账号、不添遥测 —— 这一版的每一行代码也仍然只跑在你自己的电脑上。

### 下载

- **安装版** `Clipchan-Setup-1.1.0.exe` — **推荐**。装到 `%LOCALAPPDATA%\Programs\Clipchan`，启动 0.3 秒级，可从「设置 → 应用」卸载。装完约 291MB，安装包 77MB，与上一版持平。
- 免安装版 `Clipchan.exe` — 单文件双击即用，但每次启动要先把约 290MB 自解压到 `%TEMP%\`，只在不能安装的场合使用。

装过 1.0.0 的可以在「设置 → 版本与更新」里点「检查更新」自动升级；数据库结构这版**没有变化**（schema 仍是 v5），不需要迁移、不需要卸载重装。

### ① 界面修复：Esc 与「点了没反应」

- **Esc 现在只关最上层**：浮层（详情、标签弹窗、AI 面板）优先于主面板，在整理页里先退整理状态再退面板 —— 以前按一下 Esc 会连浮层带面板一起关掉。
- 智能整理页的「规则标签」「移动到文件夹」两处**真正接上了界面** —— 1.0.0 里它们点了没有反应。

### ② 数据库更省、更快、更抗造

- **四条新索引**（相似判定 / 回收站 / seq 排序 / 图片字节），上限淘汰从逐条改成区间删除，每次复制不再全量读图片行，空闲时自动回收已删记录占用的磁盘页。
- **热路径 SQL 预编译**：去重查询、写入、淘汰这些每秒都在跑的语句只在打开时编译一次，单次复制写库省约 8–13%（实测）。
- **链接预览缓存会自己收拾了**：按 7 天新鲜期 + 最多 5000 条自动淘汰 —— 1.0.0 里这张表只增不减。
- **清空回收站一次取全**：不再一页一页跳着扫，回收站越大提升越明显。
- 需要排查性能问题时，设环境变量 `CLIPCHAN_PERF_MS=50` 再启动，主进程日志会输出每类操作耗时的观测行。

### ③ 搜索更快

- **带表达式的搜索**（`AND` / `OR` / 正则 / 时间范围…）现在一次请求同时返回结果和总数，候选扫描从读全部 23 列降到只读判定需要的 7 列，同一候选集还带缓存 —— 大库里以前每敲一个词要扫两遍两万行，现在扫一遍。
- 普通搜索（只输一个词）走的路径与 1.0.0 完全一样，日常手感不变。

### ④ 批量操作不再让界面闪

- 批量收藏 / 删除 / 连续复制时，界面刷新合并进 120ms 窗口 —— 以前同一秒能触发十几次「全量重拉」，列表就在那儿闪。

### ⑤ 数据更安全、失败更体面

- **升级失败不再等于启动失败**：数据库结构迁移万一失败，程序会先把原库自动备份一份再抛错，应用**照常启动**（历史读写暂不可用，提示写明数据都在哪），而不是弹「启动失败」直接退出。这是 1.0.0 里最脆的环节。
- 同名同级文件夹的**新建 / 重命名现在会明确报错**（「同级已有同名文件夹」）—— 以前是静默原样返回，点了「新建」像没反应。
- 图片复制从「整图解码两遍」变「一遍」：透明度判定与感知哈希共用同一份像素。
- 数据库出错时的提示**不再带英文样板前缀**，中文说明直接可见。

### ⑥ 分发与隐私

- **安装包不再内嵌源码映射**：sourcemap 等于把源码原样发给每个下载者，与本项目「转公开前脱敏」的做法自相矛盾，生产构建已关闭（需要排查问题时构建侧可临时打开）。
- 渲染层生产构建剥离调试用 `console`（保留 warn/error），设置 / 词云 / 片段 / 回收站 / 整理 / 优化六个低频视图改为懒加载，首屏更小。
- 删除了一段从未接线的「第三方图标服务候选」代码 —— 它一旦被人顺手接上就会把你复制过的域名交给第三方，与「零服务器依赖」承诺直接冲突，现在连同这段诱惑一起删了。
- 开发模式固定监听 `127.0.0.1`，不再暴露到局域网。
