## 剪贴板酱 Clipchan 1.0.0

Windows 剪贴板历史工具。Ctrl+` 唤起面板，选中即粘贴回刚才那个窗口。

这是第一个大版本。0.6.x 解决的是「出事时能不能救回来」，1.0.0 补的是**每天都会用到的那几件事**：Key 加密存、库自动备份、搜索能写条件、记录能归类、链接和图能读懂、AI 从「只会优化提示词」扩到五个通用动作，外加把包体削掉 10.6MB。

不添服务器、不添账号、不添遥测 —— 这一版的每一行代码都仍然只跑在你自己的电脑上。

### 下载

- **安装版** `Clipchan-Setup-1.0.0.exe` — **推荐**。装到 `%LOCALAPPDATA%\Programs\Clipchan`，启动 0.3 秒级，可从「设置 → 应用」卸载。装完约 291MB（上一版 316MB）。
- 免安装版 `Clipchan.exe` — 单文件双击即用，但每次启动要先把 291MB 自解压到 `%TEMP%\`，本机实测 3.0 秒（上一版 3.6 秒），慢机器上十几秒，只建议在不能安装的场合使用。

装过旧版的可以在「设置 → 版本与更新」里点「检查更新」自动升级；数据库会在首次启动时自动迁移到 schema v5，**不需要卸载重装**。

### ① API Key 不再明文躺在库里

以前 Key 是明文写进 `clipchan.db` 的 `settings` 表，共享电脑上谁拿到那个文件就等于拿到 Key。

- 现在用 Windows 的 **DPAPI**（Electron `safeStorage`，底层就是 `CryptProtectData`）加密，密文带 `enc:v1:` 前缀，**只有当前 Windows 用户能解开**。换用户、拷到别的机器上都解不开。
- **老 Key 自动迁移**：首次读取时发现是明文，就地加密并写回，用户不用重填、不用做任何操作。迁移是幂等的，失败也不致命（继续用明文，日志里留一条 warn）。
- 系统加密不可用时诚实降级成 `plain:v1:` 前缀的明文，并在日志里记一条 —— 不假装加密了。
- **明文只在主进程里出现**：渲染层拿到的永远是掩码（`sk-…abcd`），与升级前一致。

### ② 数据库自动备份，坏了先救再兜底

以前库损坏的处理是「挪开 + 新建空库」，记录不会自动救回来。现在多了两层：

- **每 24 小时自动备份一份**到 `%APPDATA%\Clipchan\backups\clipchan-<日期>-<时间>.db`，最多留 7 份，超出的按最旧删。
- 备份前先 `wal_checkpoint(TRUNCATE)` 把 WAL 并回主库，复制走 `.tmp` 再改名 —— 备份文件永远自洽、永远不会是半个。
- **损坏时先找备份**：从新到旧找第一个通过 `quick_check` 的备份，复制回来并清掉 `-wal` / `-shm`，提示「已从备份 X 自动恢复」。
- **一个可用备份都没有**才走老路径：原库改名成 `clipchan.corrupt-<时间戳>.db`、新建空库、提示「已备份为 X，将新建空库」。
- 恢复动作本身失败也照样能启动 —— 兜底那一步从来没被删掉，只是不再是第一选择。

### ⑧ 搜索能写条件了

三路搜索（原文 / 全拼 / 首字母）一个字没改，只是在它上面加了一层可选语法：

- `"手工 验收"` 短语整体匹配、`a AND b` / `a && b` / 空格隐式 AND、`a OR b`、`NOT a` / `!a`、`(a OR b) AND c` 括号分组。
- `/正则/i` 或 `re:正则` 正则匹配。
- `after:2024-01-01` / `before:2024-12-31` 时间范围，也支持 `2024-12-31T18:00`。
- 可与「只看图片 / 只看链接 / 标签 / 文件夹」任意叠加。
- 输入里出现语法特征时搜索框右边出现「?」速查入口，写错正则或日期时出现警示图标并说明哪里错了。
- **只有一个纯词时仍走原来那条 `LIKE`**，不经过解析器 —— 日常搜索的性能与以前完全一样。

刻意的宽容：`/usr/local/bin`、`a&&b` 这类看起来像语法其实是字面量的片段，按普通文本搜。

### ⑥ 智能整理：标签 + 多级文件夹

- **13 种本地规则标签**：链接 / 代码 / 路径 / 数字 / 图片 / 文件 / 邮箱 / 电话 / JSON / 颜色 / 中文 / 英文 / 长文本。纯规则，不联网、不调 AI，落库就能用。
- 每条最多 3 个标签；「中文」「英文」这类弱标签只在没有结构化标签命中时才出现（否则 `dev@example.com` 会被标成「邮箱 + 英文」，噪音大于信息）。
- **自动标签只是建议**，点「保存」才落库。
- **可选的 AI 语义标签**：「标签…」弹窗里点「用 AI 起名」，模型读一遍正文给出 3–6 个短标签并并入草稿（不直接落库）；没配模型时不出现按钮。走你自己的 Key，不经过任何中间服务器。
- **多级文件夹最多 3 层**，不允许把一棵子树挂到自己底下；删文件夹不删记录（里面的记录退回「未归类」，子文件夹提升为顶层）。
- 标签与文件夹都能当筛选条件，顶部筛选条上可一键清空。
- 新增 `folders` 表与 `items.tags` / `items.folder_id` 两列（schema v4）。

### ⑦ 链接预览、图片相似去重、二维码识别

- **链接预览**：复制公网 `http(s)` 链接后后台抓一次页面标题，卡片上显示「· 域名」。只发一个普通 GET，不带 UA / Referer / 任何本地数据；结果缓存在 `url_previews` 表里 7 天。**内网地址一个请求都不发**（`localhost` / `10.x` / `192.168.x` / `172.16–31.x` / `.local` 等）。站点图标只用链接自己主机的 `/favicon.ico`，刻意不用任何第三方图标服务。
- **图片相似去重**：每条图片入库时算 64 位 dHash（`items.phash`），与最近 200 张比对，汉明距离 ≤ 10 视为很像，弹一句「这张图库里已有一张很相似的，已照样保存」。**只提示，不拦截** —— 连着复制两次同一张图是常事，悄悄丢掉才是数据丢失。
- **二维码识别**：图片右键「识别二维码」，结果可一键复制或存为一条新记录。解码用 `jsqr`（纯 JS、无 WASM、无原生模块），先按 RGBA 解、失败再按 BGRA 换序解一次。

### ⑤ AI 助手：五个通用动作

右键文本记录 → **AI 助手…** → 选动作：

| 动作 | 做什么 |
| --- | --- |
| 翻译 | 译成简体中文 / 英文 / 日文，只给译文 |
| 总结 | 压成几句要点，保留结论、数字、人名、时间 |
| 改写 | 保持原意与语言重写一遍 |
| 解释 | 先一句话结论再分点讲清 |
| 提取要点 | `- ` 列表逐条列关键信息，最多 8 条 |

- 与「优化提示词」共用同一份「设置 → AI 模型」配置，三协议适配器、超时、错误翻译、Key 掩码全部复用。
- 结果可复制或存为一条新记录（存进去就是普通文本记录，之后能被搜索、打标签、归类）。
- 模型没按格式返回时剥壳直接用全文，面板上给黄条提示，原文照实展示、可重试。

### ④ 包体瘦身

- 剔掉三个永远用不到的 tesseract WASM 变体（约 9.9MB）：OCR 引擎固定用 `OEM.LSTM_ONLY`，非 LSTM 的三个文件一次都不会被加载。
- 剔掉 `tesseract.js/dist`、`docs`（浏览器分支才用的构建产物）与 `node-addon-api`（只有 C++ 头文件，运行时用不到）。
- 合计 **win-unpacked 301.9MB → 291.3MB（−10.6MB，64 → 60 个文件）**，安装包 81.3MB → 80.4MB，免安装版解压 3.6 秒 → 3.1 秒（省的主要是磁盘与下载，解压只快一点点，不吹成「启动快一倍」）。
- OCR 引擎本来就是首次点「识别文字」才 `require`，这一版保持并按需加载。

### 其它

- 版本号：根与四个子包、界面上的 `APP_VERSION` 全部升到 1.0.0。
- 数据库 schema 从 v3 升到 v5，首次启动自动迁移（补 `folders` 表、`items.tags` / `items.folder_id` / `items.phash` 三列、`url_previews` 表）。老库直接可用。
- 测试：85 个文件 / 1670 个用例全绿（上一版 70 个文件 / 1069 个用例）。
- **明确不做**：移动端、跨平台、长截图、OCR 批量、更新镜像。

### 隐私（一句话没变）

**所有剪贴板数据只存在你自己的电脑上，我们没有服务器，也收不到任何东西。** 没有账号、没有遥测、没有崩溃上报。

整个程序现在有**四处**会联网，没有第五处：OCR 语言包（jsdelivr，点了才下）、AI 提示词优化 / AI 助手（你自己填的 Base URL，点了才发）、链接预览（那个链接自己的域名，且只抓标题、内网不抓）、自动更新（GitHub Releases，点了才查）。

本版把本地存储的边界也往前挪了一步：**剪贴板历史仍然不加密**（能读 `%APPDATA%` 的程序就能读到你的历史），但 **AI Key 除外 —— 它现在经 DPAPI 加密，只有当前 Windows 用户能解开**。
