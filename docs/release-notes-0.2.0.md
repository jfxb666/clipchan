## 剪贴板酱 Clipchan 0.2.0

Windows 剪贴板历史工具。Ctrl+` 唤起面板，选中即粘贴回刚才那个窗口。
这一版加了 AI 提示词优化，并把上一版留下的交互缺口补齐。

### 下载

- **免安装版** `Clipchan.exe` — 双击即用，不要求安装任何运行时（首次启动会解压到临时目录，约 3–5 秒）。
- **安装版** `Clipchan-Setup-0.2.0.exe` — 装到 `%LOCALAPPDATA%\Programs\Clipchan`，可从「设置 → 应用」卸载。

### 新增：AI 提示词优化

- 卡片右侧「优化提示词」按钮，或右键菜单进入；支持用户提示词与系统提示词两种模式。
- 四类场景：通用对话 / AI 生成 / 产品·项目描述 / 日常交流。
- 三种协议：OpenAI 兼容、Anthropic、Gemini。API Key 只留在主进程，渲染层拿不到，界面上只显示掩码。
- **流式输出**：结果边生成边显示，可以随手改。超时按块算（首块 30 秒 / 块间 60 秒），实测 20 秒才出首字的慢模型也能正常完成；随时可点「停止」。
- 「复制」只写剪贴板，「直接粘贴」才贴回原窗口——两个动作彻底分开。
- 切走再回来，未提交的原文与结果还在（草稿）。

### 新增：右键菜单与查看全文

- 卡片右键：查看全文 / 查看大图 → 复制到剪贴板 → 复制并粘贴 → 优化提示词 → 收藏 → 删除。
- 「复制到剪贴板」只写剪贴板，不贴回原窗口，也不改动记录顺序。
- 长文本列表只显示前 200 字，库里最多存 10 万字；「查看全文」浮层可看完整内容并复制。
- 图片「查看大图」按原图分辨率显示，不是 64×64 缩略图。
- 搜索词在列表里高亮命中片段。

### 改进

- 状态栏「共 N 条」改为真实总数（之前是已加载条数，分页时会对不上）。
- `Ctrl+Delete` 清空未收藏需要按两次（3 秒内有效），与设置页的双击确认一致。
- 设置 → 快捷键：唤起面板与切换小组件的热键可以自己录制了（Esc 取消、Backspace 恢复默认）。
- 设置 → 快捷键：新增「Enter 自动粘贴」开关，关闭后双击记录只复制不粘贴。
- 设置 → 数据：新增「导出 JSON」，把全部记录写到数据目录。
- 卡片上的「优化提示词」与「收藏」按钮常显（之前悬停才出现）。

### 环境

Windows 10 / 11 x64。数据全部落在 `%APPDATA%\Clipchan\`。

### 已知边界

- Win10 上「毛玻璃」是窗口内模糊，不是系统级 acrylic。
- 提权窗口（以管理员身份运行的窗口）因 UIPI 无法自动粘贴，会回退为「已复制，按 Ctrl+V 粘贴」。
- 只记录文本与图片。
- API Key 以明文存放在本地 `clipchan.db`，不加密。
- 手机端只搭了壳（可构建 Web 包，无 APK、无持久化）。
