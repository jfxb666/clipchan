# 隐私说明

**所有剪贴板数据只存在你自己的电脑上，我们没有服务器，也收不到任何东西。**

剪贴板酱（Clipchan）是一个本地优先的工具：历史记录、图片、片段、设置、AI Key 全部落在本机的数据目录里，程序本身没有任何上传通道。

## 你的数据存在哪

全部在 `%APPDATA%\Clipchan\` 下：

| 路径 | 内容 |
| --- | --- |
| `clipchan.db` | SQLite 主库：历史记录、设置、片段库、优化历史、AI 模型配置（API Key 经 DPAPI 加密，见下） |
| `backups\` | 数据库自动备份（`clipchan-<日期>-<时间>.db`，最多 7 份，每 24 小时一份） |
| `images\` | 图片原图（JPEG q80 或 PNG，长边 ≤ 2560） |
| `thumbs\` | 缩略图（PNG，长边 128） |
| `ocr\` | OCR 语言包缓存（`eng.traineddata.gz` / `chi_sim.traineddata.gz`，合计约 4.7MB） |
| `logs\` | 运行日志，出问题时用来排查 |

此外可能还有 `settings.json`（旧版设置文件，新版只读不改）与 `history.json.migrated`（旧版历史导入后的留档）。

**怎么彻底删干净**：先退出应用（托盘图标右键退出，确认进程不在任务管理器里），再直接删掉整个 `%APPDATA%\Clipchan\` 目录。删掉之后历史记录、图片、AI Key、语言包缓存全部消失，不可恢复 —— 要留底的话先到「设置 → 数据 → 导出为 zip」导一份。

## 什么时候会联网

整个程序只有**四处**会发起网络请求，没有第五处。没有遥测、没有统计、没有崩溃上报、没有广告 SDK。

### 1. OCR 语言包下载

- **触发条件**：你在「设置 → 文字识别」里点「下载语言包」（首次识别某种语言前需要）。点过之后语言包落在 `%APPDATA%\Clipchan\ocr\`，后续识别**不再联网**。
- **发什么**：一个普通的 HTTPS GET 请求，**不带任何剪贴板内容**，也不带设备标识。
- **发给谁**：jsdelivr 公共 CDN（`https://cdn.jsdelivr.net/npm/@tesseract.js-data/`），下的是 tesseract.js 官方的语言包文件，落地前会做 SHA-256 校验。

### 2. AI 提示词优化 / AI 助手 / AI 起标签

- **触发条件**：只有你自己在设置里配好了模型，并且真的点了「优化」「AI 助手…」里的某个动作，或标签弹窗里的「用 AI 起名」时才请求。不点就不发。程序启动、复制、粘贴、搜索全程不碰网络。
- **发什么**：**你选中的那段文字** + 你选的场景/模式的提示词 + 你填的模型名。
- **发给谁**：**你自己填的那个 Base URL**（OpenAI 兼容 / Anthropic / Gemini 三种协议之一）。我们不知道你填的是哪个地址，也不经手任何中转 —— 请求从你的电脑直连你填的服务。

### 3. 链接预览

- **触发条件**：你复制了一条公网 `http(s)` 链接，程序在后台抓一次该页面的标题。**内网地址一个请求都不发**（`localhost` / `127.x` / `10.x` / `192.168.x` / `172.16–31.x` / `[::1]` / `.local` 等一律跳过）。
- **发什么**：一个普通 GET，**不带 UA、不带 Referer、不带任何本地数据**（连剪贴板里的其它内容都不会带）。只读回页面标题，不下载图片、不执行脚本。
- **发给谁**：**那个链接自己的域名**。站点图标也只取该主机自己的 `/favicon.ico`，刻意不用任何第三方图标服务（用第三方等于告诉它你复制了哪些链接）。
- **留存**：标题缓存在本机 `url_previews` 表里 7 天，过期才重抓；抓不到就静默不显示。

### 4. 自动更新

- **触发条件**：只有你在「设置 → 版本与更新」里点「检查更新」时才请求。**启动时不自动检查。**
- **发什么**：一个版本号清单请求（要的是 GitHub Releases 上的 `latest.yml`），不带你任何数据、不带剪贴板内容、不带使用记录。
- **发给谁**：GitHub Releases（仓库 `jfxb666/clipchan`）。发现新版本时下载安装包同样来自 GitHub。

## 我们收集什么

**什么都不收集。**

- 没有账号，不需要注册登录。
- 没有遥测、没有使用统计。
- 没有崩溃上报（崩溃日志只写本机 `%APPDATA%\Clipchan\logs\`，不会自动发出去）。
- 没有广告 SDK、没有第三方分析 SDK。

## 按应用排除（推荐立刻配一下）

「设置 → 排除的应用」里可以列出**永远不要记录**的程序，例如 `1Password.exe`、`KeePass.exe`、网银客户端。

- 从这些程序复制的内容**整条丢弃**：不落库、不出现在列表里、也搜不到。
- 判断发生在**写库之前**，是「复制的那一刻就不入库」，不是先记下来再隐藏 —— 事后翻库也翻不到。
- 填完整路径或只填 exe 名都行，程序统一取文件名比较（不区分大小写）。

## 已知的边界（如实写）

- **剪贴板历史没有加密，AI Key 有。** 剪贴板内容、图片仍以明文存在本机 `clipchan.db` 与 `images\` 里：同一台电脑上的其它程序（或能读到你用户目录的人）只要读得到 `%APPDATA%\Clipchan\`，就能读到你的全部历史。**API Key 例外**：它经 Windows DPAPI（Electron `safeStorage`，当前用户作用域）加密后存储，密文带 `enc:v1:` 前缀，换一个 Windows 用户或换一台机器都解不开。老版本的明文 Key 会在首次读取时就地加密。极少数环境下系统加密不可用，此时会诚实降级成 `plain:v1:` 明文并在日志里记一条 warn —— 不假装加密。备份目录里的 `.db` 同样含加密后的 Key，保护级别一致。
- **排除列表按 exe 文件名匹配。** 同名但不同来源的程序会被一起排除（误伤）；反过来，把程序改名成别的 exe 名就绕过了排除（漏网）。它挡的是常见的疏忽，不是对抗性攻击。
- **OCR 语言包来自公共 CDN。** 下载依赖 jsdelivr 的可用性；该请求本身不携带任何本地数据，但 CDN 运营方按常规会看到你的 IP 与请求时间，这一点与本说明中其它联网请求相同。
- **AI 请求的内容会离开你的电脑。** 这是该功能的固有代价：你点了「优化提示词」「AI 助手」或「用 AI 起名」，那段文字（或那张图的文字）就会发给你配置的服务方，请按对方的数据政策自行判断是否适合处理敏感内容。AI 请求**只在点击时发生**，程序不会在后台偷偷发。
