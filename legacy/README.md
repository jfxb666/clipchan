# 剪贴板酱 · Clipchan

一个带二次元风格的 Windows 剪贴板历史小工具，**单文件 exe、免安装、无需任何运行时**。

## 快速开始

双击 `dist\Clipchan.exe` 即可。首次运行会常驻托盘，自动开始记录复制内容。

| 操作 | 快捷键 |
|---|---|
| 唤出 / 收起面板 | `Ctrl+``` （被占用时自动降级 `Ctrl+Alt+C`） |
| 选择上/下一条 | `↑` / `↓` |
| 多选（拼接/批量删除） | `Ctrl+点击` 或 `Shift+↑/↓` |
| 复制选中项并自动粘贴回原窗口 | `Enter`（或双击；可在托盘「Enter 自动粘贴」关闭，关闭后仅复制） |
| 收藏 / 取消收藏 | `Ctrl+D` |
| 拼接多条为一条 | `Ctrl+M` |
| 删除单条 / 批量删除 | `Delete` |
| 清空未收藏 | `Ctrl+Delete` |
| 关闭面板 | `Esc` |
| 搜索 | 直接输入，实时过滤 |

托盘图标右键菜单：显示面板 / 暂停监听 / **Enter 自动粘贴** / **✨ 今日词云…** / **🕵 幽灵模式** / 设置热键… / **外观（跟随系统·浅色·深色）** / 清空未收藏 / **开机自动启动** / 退出。

### 命令行参数

| 参数 | 作用 |
|---|---|
| `--selftest` | 运行单元自检（64 项）后退出 |
| `--wordcloud` | 直接打开「今日词云」（跟随已保存主题），可做成桌面快捷方式 |
| `--ghost` / `--ghost=30` | 以幽灵模式启动（默认 10 分钟，上限 720） |

### 自定义呼出热键

托盘图标右键 →「设置热键…」：

1. 点「录制新组合」；
2. 直接按下你想用的组合键（**必须含至少一个修饰键**：Ctrl / Alt / Shift / Win）；
3. 界面会立刻检测是否被其他程序占用 —— 可用才会放行；
4. 点「保存」即时生效，并写入 `%APPDATA%\Clipchan\settings.json`，重启后保留。

点「恢复默认」可回到 `Ctrl+\``。

配置文件形如：

```json
{
  "ctrl": true,
  "alt": false,
  "shift": true,
  "win": false,
  "key": 120,
  "theme": "auto",
  "autopaste": true,
  "label": "Ctrl+Shift+F9"
}
```

`key` 是 WinForms `Keys` 枚举值（A–Z 为 65–90，F1–F12 为 112–123）；`theme` 取
`auto`/`light`/`dark`；`autopaste` 控制 Enter 是否模拟粘贴。也可以直接改这个文件再重启程序。
配置损坏时会自动回落默认值。

## 功能

### 差异化能力（同类产品没有的）

- **✨ 今日词云**：把当天复制过的内容做无词典中文分词（高频 n-gram 发现 + 虚词裁剪），
  生成一张会轻微漂浮的词云海报——别人是"时间线"，这里多一个"记忆视角"。
  托盘菜单或 `--wordcloud` 打开；右下角「⬇ 导出 PNG」一键存成 2x 高清圆角透明图，
  直接发朋友圈 / 贴周报。
- **🕵 幽灵模式**：演示、录屏、把电脑递给别人时，一键让接下来 N 分钟的复制
  **完全不写入历史**（默认 10 分钟）。期间标题栏转暗、显示"幽灵模式"徽章、
  底部提示剩余时间，到期自动恢复。也可 `--ghost=30` 直接以幽灵模式启动。
- **🔗 拼接（Ctrl+M）**：`Ctrl/Shift` 多选几条零散记录（比如表格的几列、代码的几段），
  一键合并成一条新记录，直接 Enter 复制走。收藏项不参与，避免误伤置顶内容。
- **⚡ 连续复制自动拼接**：2 秒内连续复制 3 条以上，自动识别为"同一串"——
  面板开着就直接帮你选好（底部提示变 Ctrl+M），没开则弹一次气球告知"唤出后已选好"。
  每串只提示一次，不打扰；拼接后状态自动清空。
- **📌 Enter 自动粘贴**：选中记录按 Enter，内容写入剪贴板并**自动粘贴回你唤出面板前
  正在用的那个窗口**——省掉"再按一次 Ctrl+V"。发送前逐项验证（窗口存活、未最小化、
  有真实键盘焦点落点、前台归位成功），**验证不通过一律回退**为"已复制，请手动粘贴"，
  不盲发按键。可在托盘菜单「Enter 自动粘贴」一键关闭。
- **🌗 跟随系统明暗主题**：默认跟随 Windows 的「深色模式」，也可在托盘「外观」里
  手动锁定浅色/深色。切换即时生效（监听 `WM_SETTINGCHANGE`），标题栏、卡片、
  徽标、滚动条、菜单、词云、对话框全部同步换肤。

### 基础能力

- **自动记录**：复制任何文本自动进入历史；重复内容不会产生重复行，而是提到最前。
- **确定性排序**：每条记录带单调序号，同一毫秒内连续复制也能稳定"最新在前"
  （Windows 时钟精度只有 ~15ms，纯时间戳排序会随机漂移——已根治）。
- **持久化**：保存在 `%APPDATA%\Clipchan\history.json`，重启后仍在。
- **收藏置顶**：收藏项永远排在最上方，清空时不会被删除。
- **实时搜索**：输入即过滤，中英文均支持。
- **容量管理**：
  - 普通记录 **最多 200 条**，超出自动丢弃最旧的；
  - **收藏记录不计入上限**，永远不会被自动清理（可无限累积）；
  - 单条文本上限 **100,000 字符**，超出会截断并在列表标注「已截断」。
- **类型识别**：自动区分 链接 / 代码 / 路径 / 数字 / 普通文本，列表左侧显示对应彩色徽标。

### 设计系统（大厂质感的基础）

- **设计令牌单一来源**：配色 / 字号 / 圆角 / 间距全部集中在 `Theme.cs`，
  主面板、词云、对话框、滚动条、徽标共用一套，改一处全局生效。
- **明暗双调色板**：同一套令牌名、两套取值（亮/暗），切换时画刷缓存自动重建，
  业务代码零感知；系统原生控件（搜索框占位符、保存对话框）也一并适配。
- **4px 节奏栅格**：所有间距取 4 的倍数；列表行高 52px，比旧版更透气也更省空间。
- **可读性优先的选中态**：淡粉底 + 主色描边 + 左侧指示条（WCAG AA 对比度），
  不再用整块高饱和填充牺牲文字可读性。
- **多层柔和投影**：卡片阴影分三层（近影/光晕/漫射），比单层灰影细腻一档。
- **绘制性能**：GDI 画刷/画笔全局缓存，悬停与选择只重绘变化的两行，100+ 条无闪烁。
- **二次元外观**：樱花粉→紫渐变标题栏、圆角卡片、粉色细滚动条、五角星收藏标记、
  Q 版猫娘头像（全部由代码绘制，无外部图片依赖）。
- **可拖拽调整大小**：面板边缘任意方向拖拽缩放，320×300 ~ 900×1200，尺寸会被记住。

## 数据与隐私

- 全部数据仅存本地，**不联网、不上传**。
- 历史位置：`%APPDATA%\Clipchan\history.json`（删掉即清空历史）。
- 配置位置：`%APPDATA%\Clipchan\settings.json`（删掉即恢复默认热键）。
- 程序只读取**文本**格式的剪贴板内容，忽略图片与文件。

## 已知限制

- 只处理**文本**剪贴板，暂不支持图片、富文本与文件列表。
- 默认行为是"写入剪贴板 + 自动粘贴回原窗口"：发送前逐项验证（窗口存活、未最小化、
  有真实键盘焦点落点、前台归位成功），**验证不通过一律回退**为"已复制，请手动粘贴"；
  不想让程序模拟任何按键的话，在托盘菜单关掉「Enter 自动粘贴」即可。
- 目标窗口若以管理员权限运行（而本程序不是），Windows 的 UIPI 会丢弃模拟按键——
  此时表现为"已复制但没粘上"，请在托盘关闭自动粘贴或手动 Ctrl+V。
- 为保证跨机器可移植，编译目标为 .NET Framework 4.x（Windows 10/11 自带），而非自包含的 .NET 单文件发布——后者需要额外安装 SDK。
